# Transparent-Domain-Adapted-Detection-of-ADRfrom-Pati-ent-Reviews-with-a-Faithful-Explanation-Layer
Domain-adapted, explainable adverse drug reaction (ADR) detection from patient-written drug reviews. PubMedBERT + SciBERT, adapted via weak supervision and CADEC, with attention rollout, Integrated Gradients and a hallucination guard for verifiable explanations.
